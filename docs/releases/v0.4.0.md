三角洲复盘助手的第一个公开版本（测试版）。

## 下载和安装（Windows 10/11）

1. 下载下面的 `fupan-assistant-0.4.0.zip`，解压到一个固定位置。
2. 双击 `setup.bat`，等窗口里出现绿色的“安装完成”。第一次安装要下载约 300 MB。
3. 从桌面快捷方式打开软件。

AI 分析需要你自己的 API Key（DeepSeek、通义千问、豆包、智谱任选一家）。不填 Key 也能录制，并用 Windows 自带的文字识别切局。

## 这个版本有什么

- 每局结束自动切局、找阵亡，生成阵亡前 12 秒的回放片段
- 本局修正方案和 AI 教练点评；累计数据后给出长期方案，采纳后 3 局自动复测
- 本机文字识别加 AI 看图两层识别，支持 4 家 AI 平台
- 读取电脑完整配置，可一键还原地优化系统设置，用 PresentMon 实测帧率
- B 站社区改枪码按价格区间分组，优先推荐对症的改法
- 整局录像可以保存成一个文件

## 只想看界面

不用 Windows，也不用安装，用 Docker 运行界面演示（虚构的示例数据，不含录制和分析功能）：

```bash
docker run --rm -p 8765:80 ghcr.io/onekai/delta-force-review-assistant:0.4.0
```

然后打开 http://localhost:8765 。

## 已知限制

- 录制已在 Windows 实机上跑通；文字识别和 AI 看真实对局画面的准确度还在实测校准。
- 游戏设为“独占全屏”时部分电脑录不到画面，请改用“无边框窗口”。
- 显卡温度和显存只支持 NVIDIA 显卡。

本软件不读写游戏内存、不注入、不模拟键鼠、不装驱动。它不是腾讯官方软件，也没有经过 ACE 反作弊认证。

技术原理见 [docs/ARCHITECTURE.md](https://github.com/onekai/delta-force-review-assistant/blob/main/docs/ARCHITECTURE.md)。
